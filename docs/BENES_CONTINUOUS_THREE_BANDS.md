# 三带连续斜线 Beneš 布局

本版按用户要求使用三条开关带和连续斜线级间置换。光传播方向依次为向东、向西、向东，经两次掉头保持 **西侧输入、东侧输出**。没有额外增加输出回送带或 MZI。

保留外部 100×100、内部 128×128、13 级、832 个 MZI、1664 个独立 pad、4992 个 via 和 7680 个 crossing。MZI 为 1000 × 100 μm 占位单元，接口行距 60 μm，最小弯曲半径 20 μm。每条光路仍经过 13 个 MZI。

南北各四排 pad，排距 100 μm、每排横向错开 25 μm。折叠后不同 stage 的横向位置重叠，因此按全局电学引线顺序分配 pad，不沿用单带的按级横向分组。每个端子仍独立连接到自己的 pad，M1/M2/via 层叠不变。

最佳已验证方案为 **4/5/4 级、140 μm pad 列距**：**31.506629 × 28.736588 mm**，面积 **905.393017 mm²**。相对单带 continuous（41.708596 × 10.464212 mm），宽度减少 **24.46%**，面积增加 **107.45%**。

模型中可实现光路的几何长度范围为 **106.352–112.495 mm**（包含 MZI 占位长度）。每条路径仍为 13 个 MZI，较长光程和额外弯曲的实际损耗未评估。

三带可以缩短左右尺寸，但三组 128 通道开关阵列及跨带电学引出增加纵向尺寸和光程。本版不宣称相对单带实现面积缩小，也尚未达到 20 mm 的横向软目标。

核心对齐到全局电学逃逸通道，M2 只在声明的直波导窗口跨越光路。现有两层金属通道占宽和南北 pad 扇出决定了最终外框；不能用单带宽度除以三估算成品尺寸。

## 参数和选择过程

- `interstage_routing: "continuous"`：级间使用连续斜线 A 方案，不使用 compressed 模式。
- `fold_bands: 3`：三带，方向为 0°/180°/0°。
- `band_stage_counts`：可选逐带级数，必须是正整数、长度等于带数，总和等于网络深度。未指定时沿用原有自动分配。
- `pad_distribution: "central"`、`pad_rows: 4`、`pad_row_stagger: 25`：南北四排中央 pad 银行。
- 参考比较四种逐带级数：4/5/4、6/5/2、5/5/3、5/4/4；每种分别完整布线验证 100/140 μm pad 列距。利用已有横向空间拉开 pad 列距可减少部分候选的电学扇出高度。
- 按完整 die 面积优先，再按既有均匀性次序择优；这是有界比较，不是全局最优证明。

跨带连接复用层级 fan_lane 和同心回弯，回弯处的束间距仍为 `bundle_pitch=6.01 μm`。这属于折叠连接，不意味着启用了 40 μm 的级间局部压缩方案。

## 运行与产物

```bash
# 一次生成指定三带分配，自动比较两种 pad 列距。
MPLCONFIGDIR=/tmp/layout-mpl .venv/bin/benes-layout generate \
  --config examples/benes/continuous-three-band/4-5-4.json \
  --out output/benes/continuous-three-band/4-5-4

# 比较全部四种分配，并重复生成最佳候选、独立回读。
MPLCONFIGDIR=/tmp/layout-mpl .venv/bin/benes-layout three-band-study

.venv/bin/benes-layout verify output/benes/continuous-three-band/4-5-4
.venv/bin/python -m pytest -q
```

输出包括 `layout.gds`、整体与局部预览、pad 局部图、manifest、开关设置、端口/pad 表和完整报告。比较与复现结果位于 `output/benes/continuous-three-band/study.json`；可再生配置及报告快照保存在 `examples/benes/continuous-three-band/`。

CLI 也支持 `--band-stage-counts 4,5,4`。小规模验证覆盖正序/反序行和多种合法分配；普通 `generate` 仍按参数构建 N 端口布局，`three-band-study` 固定比较本次 100/128 参考案例。

## 验证

反向带的光路方向从实际 MZI 端口与旋转角度推导，跨带回弯单独检查；不再假设所有路由都朝东。验证包括端点与切向连续、实际多边形相接、曲率下限、波导间距、crossing 对穿关系和全网络连接。

完整 GDS 回读检查层级/多边形、真实金属开短路、线宽/间距、via 包围、四排错位 pad 和跨带光电窗口。测试注入错误切向、过小半径、断点、错误逐带级数、pad 偏移及缺失光电窗口。最佳候选重复生成后核对规范化几何摘要、设置、端口/pad 表、尺寸与路径统计。

实测结果：完整回归 **259 项通过**；最终配置错误提示及预览标题调整后的相关测试 **51 项通过**。四种级数分配、两种 pad 列距的 **8 个完整候选均通过验证**；最佳候选重复生成一致，独立 GDS 回读和金属网络提取通过。原单带 continuous 产物也通过新验证器回读。报告快照见 [verification.json](../examples/benes/continuous-three-band/reports/verification.json) 与 [study.json](../examples/benes/continuous-three-band/reports/study.json)。

器件仍为占位结构；180° 旋转仅依据当前 MZI 合约允许的方向。真实 TFLN 器件替换仍需确认晶向、损耗、串扰、电极性能和封装约束。该结果不是流片签核。
