# 保持宽度的 pad 对齐与转折简化

本版按用户选择的折中方案，保留紧凑三排版的光学级位置和左右尺寸，将 pad 分布扩大到更多可用位置，让部分 pad 与 M2 引出线直接对齐。选定方案为 **36.394307 × 10.764352 mm**，总转折从 **4992 减到 3468（−30.53%）**，via 从 **8320 减到 6796（−18.32%）**。

## 改了什么

南北仍各三排，每侧 278/277/277 个 pad，共 1664 个独立端子。pad 为 60 μm 方形、纵向排距 70 μm；同排最小中心距提高到 **120 μm**，允许更大的非均匀间隔。原固定 25 μm 横向错位改为按引出位置错列，实际 pad 坐标保存在 `pads.csv`。本例同排间隔为 120–2138.152 μm，局部大间隔对应光学级之间及端点处的可用空间。

在不移动光学级的前提下，先保留满足间距的直接对齐位置，再在其余空隙放置 pad。剩余端子按位置匹配，M1 横向段按冲突区间安排高度。非对齐 pad 的 M2 引线避开异网 trunk，因此 pad 分布可以改变而不形成短路。南北 bank 仍以 y=0 对齐；逻辑网不要求逐条严格镜像。

**762 条连接（45.79%）只保留一次几何转折**：器件向右引出，再向北或南一直到 pad，途中只换层、不改变方向，每网三个 via。其余 **902 条连接**保留三次转折、五个 via。全网平均转折从 3 降至 **2.084 次**。

保留 M1/M2 两层金属、20 μm 最小弯曲半径、100 活动/128 内部端口、13 级、832 个 MZI、7680 个 crossing 和西侧输入/东侧输出。光学路由及光程与上一版一致，仍使用已有的绝缘 M2 覆盖被动置换波导合约。GDS 中器件、crossing、pad、via 和独立电网层级保持。

## 完整候选比较

以下全部候选均生成完整 GDS 并通过几何检查、回读和电学连通提取。宽度均为 **36.394307 mm**。

| 方案 / 同排最小中心距 | 高度 (mm) | 面积 (mm²) | 一次转折连接 | 总转折 | via |
|---|---:|---:|---:|---:|---:|
| 原三排 / 固定 100 μm | 10.792356 | 392.780318 | 0 | 4992 | 8320 |
| 对齐 / ≥100 μm | 12.724632 | 463.104163 | 944 | 3104 | 6432 |
| 对齐 / ≥105 μm | 11.576468 | 421.317530 | 792 | 3408 | 6736 |
| 对齐 / ≥110 μm | 11.268424 | 410.106482 | 784 | 3424 | 6752 |
| **对齐 / ≥120 μm** | **10.764352** | **391.761131** | **762** | **3468** | **6796** |

100 μm 候选转折最少，但剩余未对齐连接需要更多横向通道，导致明显增高。选定 120 μm 候选兼顾宽度、转折与面积：高度降低 28.004 μm、面积降低 0.26%，外围横向通道为 87 个 y 位置，原版为 88。它们不是额外工艺金属层。

转折少不代表总线长更短。选定版端子到 pad 的串行金属路径总长为 **9.335956 m**，原版为 **9.094478 m**，增加 **2.66%**；这是剩余连接横向绕行的代价。此数为 1664 条连接的长度总和，并非芯片尺寸或单条线路长度。统计按真实串行路径方向变化计数，不把 collinear 换层当转折，也不重复统计 via 落点旁的同网并联小桥。

这是四个有界候选的比较，不是全局最少转折或最小面积证明。完全一转折的方案需扩宽至约 45 mm，因用户选择维持现有左右尺寸，本版没有采用。

## 参数化与运行

新增 `electrical_fanout="aligned"`，限定 three-row 模式；默认 `channel` 保持原两排/三排行为。aligned 模式的 `pad_pitch` 表示同排最小中心距，至少 100 μm；channel 模式仍固定 100 μm。aligned 使用原 100 μm 规划锚定级位置，pad 间距只控制新 pad 分布；放不下时显式失败，不暗中扩大宽度或压缩间距。

```bash
MPLCONFIGDIR=/tmp/layout-mpl .venv/bin/benes-layout generate \
  --config examples/benes/aligned/pitch-120.json \
  --out output/benes/aligned/pitch-120

.venv/bin/benes-layout verify output/benes/aligned/pitch-120

MPLCONFIGDIR=/tmp/layout-mpl .venv/bin/benes-layout aligned-study
```

`aligned-study` 比较 100/105/110/120 μm、重复生成最小面积候选并独立回读。`--reuse` 复用配置匹配且已有生成检查通过的候选，最佳方案仍重新生成和回读。分配过程使用有界贪心选择与有序匹配；扩大 N 或改变占位器件参数后需重新检查容量及物理规则。

## 验证与产物

完整回归 **324 项通过**，新增测试覆盖非均匀中心距、保持原宽度与光学路由、正反行序、一次/三次转折混合路径、via 实际数量、容量不足以及 pad、via、层、路径、统计报告的故障注入。全部四个完整候选已验证，旧三排 bundle 也使用新版验证器回读。最佳候选重复生成须具有一致的几何摘要、尺寸、光程、电学统计、开关设置和端口/pad 表，并独立回读。

配置与报告快照在 `examples/benes/aligned/`；实际 GDS、全局图、pad 细节、manifest 和完整坐标表在 `output/benes/aligned/pitch-120/`。大型派生输出不纳入 Git。证据见 [验证摘要](../examples/benes/aligned/reports/verification.json)、[原版比较](../examples/benes/aligned/reports/baseline-comparison.json) 和 [研究结果](../examples/benes/aligned/reports/study.json)。

这些验证针对占位布局的几何和连接，不替代真实 TFLN 器件、绝缘层与封装工艺验证。
