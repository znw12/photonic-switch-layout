## Context

动机见 proposal.md。本变更跨越放置、金属层分配、光电合约和独立验证，因此需要设计文档。现有四排单带连续斜线版为兼容性基线。直接把 pad 改成连续两排、保持旧 M1 扇出会使最大扇出层级从 53 增至 365，估算高度约 18.8 mm。

## Goals / Non-Goals

**Goals:** 两排 100 μm 同排中心距、统一南北视觉节奏、共享置换区空间、全网络物理验证与可复现尺寸比较。

**Non-Goals:** 不要求逐网镜像；不缩小 pad、合并电气端子、改变 Beneš 图、增加金属层或光学层；不把占位绝缘合约当作真实 PDK 验证。

## Decisions

1. 新电学模式独立启用，限制为 single-band continuous、central 两排 pad。参考设置 pad_size=60、pad_pitch=100、pad_row_pitch=100、pad_row_stagger=25 μm。旧模式的默认与限制保持兼容。
2. 光学 y 原点移到通道束中心，使波导束、pad 行和外框以 y=0 为中心。南北使用相同规划规则和共同外侧扇出高度；端子编号保持正确，不强制逻辑端子上下对称。
3. 每级 M1 仅将器件端子引到紧邻 MZI 的短直波导区 via 列；此后由 M2 水平引出并转向南北。南侧按源 y 递增分配 trunk x，北侧按 y 递减分配，形成有序嵌套 L 形而无同层交叉。M2 trunk 可占用置换区横向范围；下一 MZI 放置需同时容纳光学块和金属 trunk。
4. pad 外围采用 M2 竖向 trunk、M1 横向通道、M2 竖向 pad 引线；在 pad 阵列前统一经 via 转回 M1，最后经 via 接入 M2 pad。典型每网五个 via，实际数量写入报告，不沿用旧三个 via 假设。横向区间做确定性分层，M2 trunk 与 pad 竖向轨道保持间距。
5. pad 连续排列；stage 放置在满足光学跨度、金属容量和器件间距的前提下靠近对应 pad 段，避免把压紧的核心全部放在一侧造成长扇出。比较共享与独立置换区模式，按完整面积选择。
6. 新占位合约只开放 M2 对被动 straight/segment/bend/crossing 的绝缘跨越，明确记录实际窗口及其所属光学实例。M1、via 对被动光学 keepout 保持原规则，MZI 保持自己的电极合约。不把整个置换区标为免检区域。
7. 检查实际 GDS 金属连通、同层间距、线宽、via 包围，以及每个登记跨越与真实光学实例的对应关系。报告核心、完整芯片、pad 扇出、共享宽度和 via 数量；小规模故障注入、100/128 实测、最佳重复生成并回读。

## Risks / Trade-offs

- 两排 pad 长度接近原芯片宽度 → 接受宽度由 pad 限制，完整面积作为结果，不能把核心缩短宣传为芯片同比缩短。
- M2 共享光学区仍可能受其他电线/via 限制 → 显式几何验证，失败保留原因，比较独立引出对照。
- 换层数量增加 → 报告实际 via 和金属长度，真实工艺替换后再评估电阻、寄生和良率。
- 绝缘跨越可能影响实际 TFLN 光学性能 → 本版标记占位假设，真实介质厚度及 crossing 覆盖合约须由 PDK 或仿真确定。

## Migration Plan

新增配置选择新电学模式；旧 bundle 不要求重建。先小规模验证，再完整回归及 100/128 候选比较。保留旧单带连续版文件和三带产物，输出新目录、示例配置与报告，提交 Git。
