## Context

动机见 proposal.md。当前分层布线和 pad 生成大部分已按排数参数化，但配置和若干验证分支仅接受 two-row。三排每侧 832 个 pad 存在不完整末列，不能按满列推算外框。

## Goals / Non-Goals

**Goals:** 使用三排缩短整体横向跨度，重新规划 stage 与 pad 的相对位置，以完整面积评价；保留南北协调、层级和独立验证。

**Non-Goals:** 不改变 MZI、光学图、金属线宽/间距、100 μm pad 同排中心距，不增加金属层，不强制镜像电气网络。

## Decisions

1. 新增 `electrical_routing="three-row"`，严格对应 pad_rows=3；two-row 仍严格对应 2。共享核心路由器，旧模式及旧生成结果不变化。保留单带 continuous、central pad、绝缘 M2、五个 via/net 合约。
2. pad_rows 决定槽位及末列覆盖，参考每侧行计数 278/277/277，逐排 x 偏移 0/25/50 μm。以真实最小/最大 pad 坐标计算外框。
3. 三排缩短 pad 阵列后，核心及扇出可能成为限制。新增可参数化的 stage 横向对齐偏置与额外布局宽度（均默认零、旧模式不得使用），只改变合法位置区间内的期望位置及可用空间，不改变 pad 中心距。确定性有限扫描偏置和额外宽度，先通过规划尺寸筛选，再对少量候选生成完整 GDS。紧密排布时偏置可能全部被合法区间截断，因此额外宽度用于比较略宽但更矮、总面积更小的候选。
4. 记录未经偏置优化的三排共享基线、筛选出的改进候选和独立引出对照；保留失败原因，以完整面积、既有均匀性顺序择优，不把解析规划尺寸作为物理通过证明。
   同时比较已有 margin=100/80/60/40 μm 与 pad_row_pitch=100/80/70 μm 参数；这只压缩预留空白和纵向排距，100 μm 同排中心距与 25 μm 横向错位保持不变。所有候选须满足原配置及实际金属/光学间距规则，真实封装边距仍待工艺确认。
5. 检查三排末列、精确中心距、错位、y=0 对齐、M1/M2/via、实际跨越窗口与完整 Beneš 光路；最佳重复生成和独立回读。原 two-row bundle 需用新代码回读证明兼容。

## Risks / Trade-offs

- 三排多占一排高度，且更密集的 M2 pad 引线占用轨道 → 以实际宽高与面积比较，保留不利候选。
- 对齐偏置可能只改变宽度不改变高度或无收益 → 有界扫描并报告无收益，不承诺全局最优。
- 占位 M2 跨越合约仍需真实 TFLN 工艺验证 → 原限制与标注保持，不放宽光电间距。

## Migration Plan

新增 three-row 示例和独立输出目录，旧 two-row 示例保留。小规模测试、完整回归、100/128 候选比较、最佳重复生成和回读后保存报告与 Git 提交。
