## Context

见 proposal.md。用户明确选择保留现有左右尺寸的折中方案；全部引出对齐约需 45 mm 宽，不作为本次目标。

## Goals / Non-Goals

**Goals:** 保持原光学和级放置，在同一横向边界内安排非均匀三排 pad，尽量减少总转折与换层，报告实际宽高代价。

**Non-Goals:** 不要求所有线路一次转折，不保持原固定 25 μm 排间错位，不改变光学单元或放宽间距规则。

## Decisions

1. 在 three-row 模式下新增 `electrical_fanout="aligned"`，默认 `channel` 保持旧结果；`pad_pitch` 在新模式表示同排最小中心距，至少 100 μm。光学级放置继续以原 100 μm pad 规划为锚点，用户的 pad 间距参数只影响新 pad 分布。
2. 先按各级 M2 引出 x 值选取可直接对齐的 pad，逐排检查中心距、全部引线与 via 落点间距；再在当前横向边界内填充剩余 pad。每侧排数和端子覆盖保持 278/277/277，x 间距允许扩大且非均匀，南北 bank 同位置。
3. 未对齐 pad 必须避开所有异网 M2 trunk，剩余端子按 x 顺序匹配剩余 pad，以减少这部分横向线长。M1 横线采用区间调度；不强制所有端子的 pad 顺序相同。
4. 对齐网采用 M1 短引出、M2 横向与竖向、pad 前 M1 竖向三 via 路径，只有一次几何转折。未对齐网保留五 via、三次转折的已验证路径。对齐网不占用横向扇出通道；换层本身不计几何转折。
5. 比较最小同排间距 100/105/110/120 μm 的有界候选，筛选规划结果后完整生成，按宽度保持、转折减少和实际面积评估，不宣称全局最优。
6. 独立核对非均匀 pad、路由段与 via 几何，统计实际方向变化。新报告不能仅用少画段数声称减少转折。旧三排 bundle 继续回读兼容。

## Risks / Trade-offs

- 对齐优先可能令剩余网横线变长 → 保存全网线长和完整面积，比较候选。
- 可用空隙不足 → 参数规划失败并明确报错，不缩小 pad 中心距、不扩宽隐藏外框。
- 参数化 pad 的非均匀错位需要封装配合 → 交付真实 pad 坐标表，仍为占位工艺。

## Migration Plan

新增示例和独立输出目录。参数/小规模故障测试、完整候选物理验证、最佳重复与旧 bundle 回读后交付并提交 Git，原三排配置与产物保留。
