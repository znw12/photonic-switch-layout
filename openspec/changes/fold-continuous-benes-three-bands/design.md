## Context

现版 continuous 单带已通过完整验证，尺寸 41.708596 × 10.464212 mm。用户本轮选择三带 continuous，优先缩短左右尺寸，同时以完整面积比较三带候选。

## Goals / Non-Goals

- 目标：三带、两次掉头、左右异侧 IO，完整光电连接和全部独立 pad。
- 保留 R≥20 μm、60 μm MZI 接口行距、显式 crossing、两层金属/via；南北各四排、25 μm 排错位。
- 非目标：本轮不折叠 compressed 模式、不实现两带输出回送，不承诺 20 mm 达标或相对单带面积缩小。

## Decisions

1. 三带方向为 0°/180°/0°，使用现有层级 fan_lane 和同心回弯；级间仍为 continuous SPLIT/MERGE。回弯压束间距是已有 bundle_pitch=6.01 μm，与级间局部压缩模式不同。
2. 新增可选 band_stage_counts；默认沿用现有自动分配。显式分配必须为正整数、长度等于带数且总和等于完整 Beneš 深度。100 端口参考比较 4/5/4、6/5/2、5/5/3、5/4/4，先用现有列/通道占宽模型筛选，再完整布线比较；同时比较 100/140 μm pad 列距（pad_factors=1.0/1.4），利用现有横向空间减少电学扇出高度；pad 本体、排距与 25 μm 错位不变。不宣称全局最优。
3. 保留中央南北四排 pad 银行，以全局逃逸 x 顺序分配，独立 net/开关标识不变。单带按 stage 分组仍保留；不把新的 folded 配置静默转换成其他 pad 方案。
4. 切向验证从实际 MZI 源/目标端口及其角度推导，不能假设整条光路从始至终朝东。边界宽度检查包含 stage 朝向符号。新模式使用可反向传输的圆弧合约，旧 bundle 单向圆弧保持兼容。
5. 验证所有跨带光路、回弯半径、端点/切向、实际多边形相接、显式 crossing 数；GDS 回读提取全部金属，验证跨带 M2 只经过声明的直波导窗口。

## Risks / Trade-offs

折叠缩短宽度，但增加高度、光程以及长金属干线，完整面积可能比单带大。当前列对齐与公共垂直逃逸通道限制横向缩小；只报告完整验证的实测结果。

## Migration Plan

保留旧默认与历史产物。先验证小规模和反序行，再生成完整 100/128 候选，按现有面积/均匀性目标择优、重复生成并回读。独立输出目录为 output/benes/continuous-three-band，配置与报告快照位于 examples/benes/continuous-three-band。
