## Context

本设计跨越几何、放置、验证和产物接口，因此需要独立设计文档。动机与范围见 proposal.md。

### 已观察到的实现

- 基线为 `examples/benes/distributed/pitch60.json`，结果记录在其 `reports/pitch60.json`；完整尺寸 45.486328 × 10.464212 mm、475.978579 mm²。横向分解：MZI 13.000000 mm、置换 18.376560 mm、电学逃逸 12.039716 mm、其余 2.070052 mm。
- `geometry.Library.shuffle_block` 使用三角形相邻交换列，正向 SPLIT 和反向 MERGE 共享 EXCHANGE；每个 EXCHANGE 有一个旋转 45° 的正交 CROSSING 和四个圆弧实例。
- `reshape.build_reshaped` 从置换模块宽度推导 stage x、独立电学逃逸区、光接口和 pad 分组。缩短置换区后必须重新计算这些位置，不能仅替换报告尺寸。
- `folds.fan_lane` 是为折叠束设计的两个 90° 弯曲，要求足够纵向位移；不能直接用于 B 中小于两倍半径的局部收束。
- `verify.optical_objects` 目前将 EXCHANGE 作为空间对象，公共坐标变换仅支持正交旋转；验证器对 EXCHANGE 长度与弯曲数也有特定公式。新结构必须扩展验证粒度和方向处理。
- `workflow.candidates` 目前只枚举 gap、row、pad、corridor。候选评分已按完整 die 面积优先、均匀性其次；现有 186 项回归包含几何故障注入和真实金属提取。

## Goals / Non-Goals

**Goals:**

- A、B 提供可运行的参数化、层级化置换路由，并产生完整 100/128 布局证据。
- 固定 Beneš 图和外部接口逻辑，显式记录物理排布；将可布通、尺寸收益与真实性能三个结论分开。
- C 提供可复核的 8/16 端口重排实验，包括 IO、电学、pad 和全局交叉统计。
- 保留旧配置的几何行为和旧产物回读能力。

**Non-Goals:**

- 本轮不将 C 推广到 100 端口，不实现任意角度/任意曲线通用布线器，不改变求解器或开关数量。
- 不增加光学层、不改真实器件、不重新折叠光学带、不缩短 MZI；不保证 20 mm 达标或全局最优。
- Euler 弯曲为文献参考；本轮 A/B 先使用已支持的解析圆弧，避免同时改变弯曲模型和置换组织。真实 Euler/PDK 替换另行规划。

## Decisions

### 1. 参数和兼容性

新增建议接口 `interstage_routing = legacy | continuous | compressed`，默认 `legacy`；新增 `shuffle_pitch`，只作用于 `compressed` 内部的纯光学区域，外部端口仍遵守 `lane_pitch`。未压缩模式不得静默接受一个实际上被忽略的局部间距；非法、非有限、离网格或不适用组合明确报错。

新 A/B 参考模式限定于当前单条带、按级分组四排 pad 配置。旧模式的一至四排、已支持的折叠和行序继续保持行为。保持 0.001 μm 数据库网格；新的配置字段缺省值允许旧配置及旧 bundle 回读。

示例固定：100/128 端口、60 μm MZI 端口行距、1000 × 100 μm MZI、20 μm 半径、60 μm 方形 pad、组内 100 μm 列距/排距、25 μm 排错位、单条带、两层金属和三个 via/net。A/B 保留 832 MZI、1664 pad、4992 via、56 备用端口终止和每路径 13 级。Crossing 几何保持现有占位尺寸与 90° 对穿接口。

### 2. A：连续斜线与单元层级

在一个 SPLIT 内，按其固定置换推导每条波导的连续上升、下降或水平轨迹。同方向连续交换共享斜直段，仅在需要进入/离开斜段时使用半径明确的弯曲。MERGE 使用严格的逆连接和可验证的几何变换，不靠修改网络拓扑实现。

保留置换 block 层级；内部复用显式 CROSSING、斜直段和圆弧。每个 crossing 只有一个物理实例，两条光路分别引用其对应对穿轨迹。不得将整片置换多边形扁平化并丢失 crossing 标识，也不得将整个 block 作为免检黑盒。

完整外部接口、逻辑传输表、中心线段、长度、弯曲与 crossing 计数都进入 manifest。同参数同规模模块共享 cell；命名/缓存键包含模式、规模、局部间距和方向，避免不同候选串用单元。

对 size=2m、p=60 μm、R=20 μm 的正向模块，旧宽度约为 `(m-1) × [p + 2R(sqrt(2)-1)]`，连续斜线的解析目标为 `(m-1)p + 2R(sqrt(2)-1)`。12 个置换边界合计约 14.598828 mm，固定其余占宽时整片约 41.708596 mm。该值仅为检查趋势的估算，不作为伪造尺寸或通过验收的依据。

### 3. B：独立间距与完整过渡

模块接口保持 60 μm 行距，内部组合为：

```text
60 um ports --> fan-in --> continuous crossing array --> fan-out --> 60 um ports
```

每个递归 size 子块独立处理，不在整片 128 条波导之外创建额外光学带。初始参考扫描固定为 q=40、45、50、55、60 μm，记录明确的尝试顺序；q=60 为零收束对照，不冒充压缩结果。参数仍可配置，几何可行性由真实占用决定，不能用 `mzi_height` 限制纯光学局部间距。

采用保持波导顺序的成束收束/展开，弯曲、错列和必要直段全部计入模块宽高。小位移使用能满足端点切向与 R>=20 μm 的解析 S 形连接；不可直接套用需要 delta>=2R 的折叠 fan_lane。波导在整个过渡区都须满足间距，不能只检查入口和出口中心。

对每个规模比较 `W_fanin + W_crossing + W_fanout` 与 A 的完整模块宽度。允许经过明确记录的逐规模选择，在不划算的边界保留 A；记录实际使用压缩的边界与 q。全 A 回退必须被标记为无压缩收益，不能宣称 B 已获改善。至少一个 q<60 的真实压缩完整候选须进入全尺寸物理验证；不能只交付解析估算或 q=60 对照。

A/B 使用相同的紧凑 gap/corridor/pad 参数组进行主对照，不同时扫描无关参数造成归因混淆。当前 `max_candidates=1` 的示例不能截断整组模式比较；每个显式模式/q 配置独立生成 bundle，再由比较流程择优。

### 4. C：有限的小规模排列实验

本轮仅在 active=internal=8、16 上开展。保持每级 MZI 数和同一 x 列，只改变 MZI 上下排列及合法的端口映射；不采用专利中的完整横向嵌套/新器件方向，避免扩大成全新放置器。后续若需横向嵌套应另行立项。

导出逐级 `logical switch -> physical row` 双射及显式 pin 映射。规范 Network、逻辑 switch ID、求解状态和外部端口编号保持不变。默认 normal/reverse 行序也必须能表示为该映射，以便独立核对。

候选包括恒等排列、递归子组交换、子组内反序、按 switch 索引位反转形成的顺序。使用确定性有限搜索：从恒等候选开始，前向/后向逐级尝试这些变换，去重，固定 tie-break，最多 128 次逻辑评分；第一和最后一级固定为基准排列，保留外部接口。实际尝试次数与预算耗尽情况写入报告。

以所有边界的逆序数总和及最大位移作筛选代理，不把它们当成 die 面积。选择恒等对照及最多 8 个不同候选进行真实小规模光电布线。C 的恒等和重排候选使用相同的确定性相邻交换调度后端，以免混入 A 与旧路由器的性能差异；另列现版/A 的参照结果，明确后端差异。

每个已生成候选必须验证全网络连接、输入输出、金属和 pad；失败保留具体原因。即使没有改善，只要完成约定的搜索和物理比较，也给出“在该预算内无收益”的有效实验结论，不能假设重排必然减少面积。100 端口部署不属于 C 的完成条件。

### 5. 独立几何与连接验证

扩展验证器，使斜直段、单独 crossing 和弯曲成为可检查对象。不要简单移除当前正交旋转断言：明确支持需要的 45° crossing 变换或在定向 wrapper 内表达，统一网格吸附，并验证端口位置及切向连续性。当前占位 CROSSING 明确声明允许方向；真实替换 cell 按其允许方向检查，禁止默认无限制旋转。

在每个交叉窗口内仅豁免所属两条对穿波导的合法重叠；窗口以外、第三条波导及相邻 crossing 仍需空间间距检查。从基本段重算长度、弯曲数、曲率下限和交叉数，不只相信新 block 的汇总 metadata。

对 C，先独立验证每级映射是完整双射，再将几何端口还原到规范图，逐边验证。端子来源和 pad_group 继续依赖逻辑 stage，不随物理 row 错绑。不得通过只比较求解器自己的输出证明连接正确。

必须保留 GDS 多边形与层级回读、真实金属连通提取、宽度/间距/via enclosure、光电窗口和整体外框检查。旧 bundle 的可选新字段缺省兼容；新 bundle 必须包含可重算的新模式/映射信息。

### 6. 搜索结果和测量口径

主比较目录建议为 `examples/benes/interstage/` 和 `output/benes/interstage/`，不同模式使用独立输出目录，保留现有 distributed 基线。报告包括总宽高/面积、每个边界的核心与过渡宽度、实际局部间距、全芯片与每路径 crossing、圆弧数、路径长度范围、pad/fanout 包围盒、验证结果、生成耗时、GDS 大小和规范化 hash。

评分继续优先完整 die 的整数网格面积，再按现有均匀性次序决胜。只有完整验证通过的候选可被推荐；若新候选较差，保留基线。展示 Pareto 宽度/面积、软 20 mm 目标和失败原因，不隐藏比基线差的结果。

对 A/B，在固定边界次序且过渡无额外交叉时，100/128 总 crossing 应保持 7680；C 使用独立重算后的真实数字。所有模式保留 13 级（小网络按相应 Beneš 深度），不把等开关深度写成等光学损耗。

## Risks / Trade-offs

- 紧凑 diagonal 在端口或 crossing 接近区违反间距 → 小规模模块先做实体几何检查，空间不足增加真实过渡或拒绝候选，不放宽阈值。
- B 的收束开销抵消核心缩小 → 报告两端开销与完整 die，允许不采用无收益的边界压缩。
- 级间缩短造成 pad 组或电线拥塞 → 重新生成电学与 pad；只比较最终外框，不沿用旧高度。
- C 的逆序数改善不代表可布线面积改善 → 同后端恒等对照、完整小规模 GDS、失败记录与全局评分。
- 任意改变晶向影响真实 TFLN crossing 性能 → 本轮只声明占位几何允许方向，接口保留真实器件限制；不移植硅光性能数据。
- 新验证单元粒度增加运行量 → 继续复用层级、空间索引及有界候选；记录全尺寸生成/回读时间，不预先承诺更大规模物理可行。

## Migration Plan

先为旧结果建立兼容性对照，再新增独立模式和显式参数；现有默认不改变。验证顺序为模块 4/8/16/32/64/128 的正反置换、小规模完整布局、A/B 的 100/128 全尺寸布局、C 的 8/16 实验、最佳已验证候选重复生成。

后续实施交付完整回归、独立 GDS 回读、规范化几何重现、可再生配置与文档，并提交 Git。回退为选择 `legacy` 或此前 `distributed/pitch60.json`；本规划阶段不修改代码或生成新候选 GDS。
